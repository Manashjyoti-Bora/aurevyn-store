# নিবোৰা (Nirvora) — সম্পূৰ্ণ অসমীয়া গাইড

এই ফাইলখনে গোটেই ৱেবছাইটটো অসমীয়াত বুজাইছে — ই কি, কেনেকৈ কাম কৰে, আপুনি
(মালিক) কি কৰিব লাগিব, আৰু কিহত বিশ্বাস নকৰিব। ক'ড নজনাকৈও ইয়াক পঢ়ি আপুনি
দোকান চলাব পাৰিব।

লাইভ ৱেবছাইট: `https://zenvorastore.vercel.app`
এডমিন পেনেল: `/admin` (পাছত আপোনাৰ নিজা ডমেইনত যাব)

---

## ১. নিবোৰা কি?

নিবোৰা এটা **ভাৰতীয় অনলাইন দোকান** (reselling / dropshipping মডেল)।

কামৰ ধাৰা চমুকৈ:

```
আপুনি মেছ' (Meesho)ৰ পৰা পণ্য বাছনি কৰে
        ↓
ৱেবছাইটত সেই পণ্যৰ নিজা মূল্য (মাৰ্জিন সহ) দি প্ৰকাশ কৰে
        ↓
গ্ৰাহকে UPI QR ৰে টকা দিয়ে বা Cash on Delivery (COD) বাছে
        ↓
আপুনি মেছ'ত অৰ্ডাৰ দিয়ে (নিজৰ হাতৰ পৰা)
        ↓
মেছ'ৰ পৰা গ্ৰাহকলৈ পোনপটীয়াকৈ ডেলিভাৰি হয়
        ↓
ক'ফাউণ্ডাৰ (AI টীম) ৱেবছাইটত অৰ্ডাৰ আপডেট, মেছেজ, ট্ৰেকিং চম্ভালে
        ↓
প্ৰকৃত লাভ (profit) এডমিনত স্বয়ংক্ৰিয়ভাৱে হিচাপ হয়
```

গুৰুত্বপূৰ্ণ কথা: **পণ্য মেছ'ই পঠিয়ায়, কিন্তু গ্ৰাহকৰ সৈতে সম্পৰ্ক আৰু টকা
আপোনাৰ নিজৰ**। সেয়ে মাৰ্জিন আপোনাৰ।

## ২. গ্ৰাহকে কি দেখে (storefront)

| পৃষ্ঠা | কি আছে |
| --- | --- |
| `/` (মুখ্য পৃষ্ঠা) | মাৰ্কা, শ্ৰেণী, "Deals", "Featured", "New arrivals", ক্ৰয়ৰ নিয়ম, গ্ৰাহকৰ মতামত (কেৱল প্ৰকৃত) |
| `/shop` | সকলো পণ্য — শ্ৰেণী, দাম, সৰ্ত (sort), পৃষ্ঠা ভাগ |
| `/products/<slug>` | পণ্যৰ ফটো, দাম, ষ্টক, বিকল্প (size/colour), বিৱৰণ, প্ৰকৃত ৰিভিউ |
| `/categories/<slug>` | শ্ৰেণী অনুসৰি পণ্য |
| `/search` | সন্ধান |
| `/cart` → `/checkout` | ঝুৰি আৰু অৰ্ডাৰ দিয়া |
| `/checkout/payment/...` | UPI QR স্কেন কৰি টকা দিয়া, UTR নম্বৰ দিয়া |
| `/track` | অৰ্ডাৰ নম্বৰ + ইমেইল দি ট্ৰেকিং |
| `/account` | নিজৰ অৰ্ডাৰ, ঠিকনা, প্ৰফাইল |

ভাষা: ইণ্টাৰফেচ ইংৰাজীত (ভাৰতীয় গ্ৰাহকে বেছি বুজে), কিন্তু এই গাইড আৰু
চহায়ৰ সহায় আপুনি অসমীয়াত দিব পাৰে।

## ৩. অৰ্ডাৰ কেনেকৈ সম্পূৰ্ণ হয় (ধাপে ধাপে)

1. গ্ৰাহকে ঝুৰিত পণ্য যোগ কৰে।
2. চেকআউটত ঠিকনা দিয়ে (PIN ক'ড ভাৰতীয় নিয়মত চেক হয়)।
3. পেমেন্ট:
   - **UPI QR** — QR টো আপোনাৰ নিজৰ UPI ID লৈ টকা পঠিয়ায় (কোনো গেটৱে নাই,
     কোনো কমিচন নাই)। গ্ৰাহকে UTR/Ref নম্বৰ লিখে।
   - **COD** — টকা ডেলিভাৰিৰ সময়ত।
4. আপুনি এডমিনত UTR টো বেংক ষ্টেটমেণ্টৰ সৈতে মিলাই "paid" কৰে।
5. অৰ্ডাৰ স্বয়ংক্ৰিয়ভাৱে "SUPPLIER" লৈ যায় → আপুনি মেছ'ত অৰ্ডাৰ দিয়ে।
6. মেছ'ৰ পৰা অহা ID টো এডমিনত "Record Meesho ID" ত পেষ্ট কৰে
   (`MEESHO-XXXXXXXX` ধৰণে)।
7. তেতিয়া ক'ফাউণ্ডাৰে গ্ৰাহকলৈ অৰ্ডাৰ প্ৰক্ৰিয়াকৰণ, শ্বিপিং, ডেলিভাৰিৰ
   ইমেইল/মেছেজ পঠিয়ায়।
8. ডেলিভাৰিৰ পিছত প্ৰকৃত লাভ হিচাপ হয় (supplier cost + shipping + fee +
   ৰিফাণ্ড বাদ দি)।

গুৰুত্বপূৰ্ণ: ৱেবছাইটে নিজে মেছ'ত অৰ্ডাৰ **দিব নোৱাৰে** — মেছ'ৰ ৰাজহুৱা
অৰ্ডাৰ API নাই। সেয়ে অৰ্ডাৰ দিয়াৰ কামটো আপোনাৰ হাতত থাকিব (মাত্ৰ ১ মিনিট)।
বাকী সকলো স্বয়ংক্ৰিয়।

## ৪. টকা-পইছা (মূল্য আৰু লাভ)

- সকলো দাম **paise** হিচাপে পূৰ্ণসংখ্যাত হিচাপ হয় — দশমিকৰ ভুল নহয়।
- দামত **GST সোমাই আছে** (ভাৰতীয় B2C ৰীতি), সেয়ে গ্ৰাহকে দেখা দামেই চূড়ান্ত।
- মাৰ্জিন তিনি ধৰণে দিব পাৰে: fixed price, fixed margin, বা শতাংশ markup।
- **মাৰ্জিন = লাভ নহয়।** প্ৰকৃত লাভ = বিক্ৰী − supplier cost − shipping −
  গেটৱে/COD fee − ৰিফাণ্ড। এইটো এডমিন → Analytics ত দেখিব।
- ন্যূনতম লাভৰ তলত যাব নোৱাৰে (min-profit floor)।

## ৫. এডমিন পেনেলত কি কি আছে

এডমিন `/admin` ত। প্ৰধান অংশসমূহ:

| অংশ | কাম |

| Categories | শ্ৰেণী |
| Sourcing (Meesho) | মেছ'ৰ পণ্যৰ স্ক'ৰিং — কোনটো প্ৰকাশ কৰিব |
| Supplier orders | supplier অৰ্ডাৰ, "Record Meesho ID" |

| Inventory | ষ্টক, প্ৰকাশ/লুকুওৱা |

| Customers / Messages | গ্ৰাহক, যোগাযোগ বাৰ্তা |

| Analytics | বিক্ৰী, লাভ, শীৰ্ষ পণ্য, CSV export |

| Logs / Health | জব কিউ, webhook, অডিট লগ, ছিষ্টেম স্বাস্থ্য |

### এডমিন প্ৰৱেশ

1. `/auth/login` ত আপোনাৰ এডমিন ইমেইল + পাছৱৰ্ড দিয়ক।
2. পাছৱৰ্ড কেতিয়াও কাৰো লগত share নকৰিব — চেটত পঠিওৱা হ'লে লগে লগে
   সলনি কৰক (`npm run db:reset-admin-password`)।
3. প্ৰথম কাম: **Settings → Payments** ত নিজৰ **UPI ID** (যেনে
   `yourname@okhdfcbank`) দিয়ক। নিদিলে UPI QR নুখুলে আৰু কেৱল COD চলিব।

## ৬. মেছ' ছ'ৰ্চিং (Sourcing) — কেনেকৈ ভাল পণ্য বাছিব

মেছ'ৰ ৰাজহুৱা API নাই, গতিকে স্ক্ৰেপিং নকৰি এটা **সৎ** পদ্ধতি ব্যৱহাৰ কৰা হৈছে:

1. মেছ'ৰ পৰা পণ্যৰ তথ্য (নাম, cost, weight, ৰেটিং, ৰিভিউ, trend) আপুনি
   কপি কৰি `/admin/sourcing` ত পেষ্ট কৰে (CSV/শাৰী).
2. ছিষ্টেমে ১০০ নম্বৰৰ ভিতৰত স্ক'ৰ দিয়ে:
   - মাৰ্জিন — ৪০
   - ৰিটাৰ্ণৰ সম্ভাৱনা (কম ভাল) — ২০
   - চাহিদা — ২০
   - ৰেটিং — ১০
   - trend — ১০
3. সিদ্ধান্ত: **PUBLISH / WATCH / REJECT**।
4. **ৰিটাৰ্ণৰ হাৰ জনা নাথাকিলে কেতিয়াও PUBLISH নহয়** — কেৱল WATCH।
5. বাছনি কৰা পণ্যৰ পৰা এক ক্লিকত **DRAFT** পণ্য হয়। প্ৰকাশ (publish) কেৱল
   আপুনি নিজে কৰিব — AI এ নিজে ৰাজহুৱা নকৰে।

নিয়ম: কম দাম, কম ৰিটাৰ্ণ, ভাল ৰেটিং, উচ্চ মাৰ্জিন — এইবোৰ একেলগে চাব।
কেৱল "সস্তা" চাই নহয়, ৰিটাৰ্ণ বেছি হ'লে লাভ শূন্য হয়।

## ৭. ক'ফাউণ্ডাৰ (AI টীম) আৰু মাত

- `/admin/cofounder` ত ৮ জনীয়া AI টীমে ৰোজৰ অৱস্থা কয়।

  "24×7" বুটাম অন কৰিলে প্ৰতি ৫ মিনিটত পৰিৱৰ্তন হ'লে মাতিব।
- ক'ফাউণ্ডাৰে কেৱল **প্ৰকৃত তথ্য** কয় (আজিৰ অৰ্ডাৰ, ষ্টক, UPI স্থিতি)।
  কোনো কল্পিত সংখ্যা নাই।
- গুৰুত্বপূৰ্ণ সিদ্ধান্ত (দাম, ৰিফাণ্ড, পণ্য প্ৰকাশ) AI এ নিজে নলয় — আপুনি
  অনুমোদন দিব।

## ৮. SEO — Google ত দেখুওৱাৰ বাবে কি কৰা হৈছে

ক'ডত সম্পূৰ্ণ হৈছে: `sitemap.xml`, `robots.txt`, canonical tag, meta title,
meta description, প্ৰতি পৃষ্ঠাত এটা `<h1>`, ছবিৰ alt text, schema markup
(Product, Offer, Breadcrumb, ItemList, FAQ, Organization), OG image
(`/og-image.png`), HTTPS/HSTS, পৰিষ্কাৰ slug।

বিতং তালিকা: [`docs/SEO.md`](SEO.md)।

**আপুনি কৰিবলগীয়া:**
1. নিজা ডমেইন Vercel ত যোগ কৰি `APP_URL` সলনি কৰক।
2. Google Search Console ত DNS TXT ৰে verify কৰক (বা
   `GOOGLE_SITE_VERIFICATION` env দিয়ক)।
3. `https://yourdomain.com/sitemap.xml` submit কৰক।
4. প্ৰতিটো প্ৰকাশিত পণ্যৰ URL "Request indexing" কৰক।
5. Backlink: Instagram bio, WhatsApp Business, Facebook Page, supplier ৰ
   "where to buy" পৃষ্ঠা। **কেতিয়াও** টকা দি backlink নকিনিব।
